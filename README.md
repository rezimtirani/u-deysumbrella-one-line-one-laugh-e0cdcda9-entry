One joke, one line: an agent that books the dentist, the flights, and the wedding, leaving its owner to simply turn up where the calendar says and smile at whoever looks familiar. The entry program writes that line to `entry.txt` with nothing else — standard library only, no trailing newline, and a 140-character sealed gate enforced before writing.
